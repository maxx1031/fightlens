# FightLens visual demo

## English arcade interface

See [arcade/index.html](arcade/index.html) for the audience HUD and data console,
or [arcade/analysis.html](arcade/analysis.html) for the full measurement curves.
Download or clone the repository and open the HTML locally. GitHub shows the
source rather than hosting the interactive page. Keep the arcade assets together.
The demo replays recorded footage and precomputed measurements; no live inference
or database connection is included.

## Scripted concept video

Download or clone this repository and open `examples/index.html` in a browser.
Keep `index.html`, `preview.jpg`, and `fightlens-mock-demo.mp4` together.

The 22-second video demonstrates two 3D impact avatars, hit effects, blocks,
and accumulated head/body/leg contact counts. All fight animation and events
are scripted; no AI inference or real fight footage is used.

GitHub displays HTML source rather than running the page. Open the downloaded
HTML locally to play the demo.
